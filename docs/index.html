在课简中安装

打开课简的「组件」市场，搜索名称并安装。也可以从组件仓库的 Release 下载组件 ZIP，再用「导入 ZIP」安装。

安装后按组件页面完成登录或通知绑定。兼容版本以组件详情为准；后台同步和消息送达受系统、网络与平台授权影响。

把你的组件加入收录

注册表和应用市场共用 components.json。提交仓库地址与搜索别名，合并后由工作流更新收录资料。

在 GitHub 编辑 查看贡献说明

准备组件包

组件包声明 kind: extension，并提供兼容的 manifest.json、入口脚本和 checksums.json。Release 附件需要同时上传组件 ZIP 与下载清单 manifest.json。

注册条目示例

{
  "repo": "your-name/your-component",
  "aliases": ["我的组件", "my-component"]
}
